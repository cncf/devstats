# Bots

Bots, CI/service accounts and AI coding agents are excluded from actor related metrics via the `{{exclude_bots}}` partial (see [docs/excluding_bots.md](docs/excluding_bots.md)). The single source of truth is [util_sql/exclude_bots.sql](util_sql/exclude_bots.sql): one line `not like all(array['pattern', ...])`, applied to `lower(login)` - so patterns must be lower case, `%` is a wildcard and `_` matches exactly one character (`'github-harold_pins'` also matches `github-haroldxpins`, this is harmless).

## Adding a new bot

- Edit `util_sql/exclude_bots.sql` only (keep it a single line, keep patterns sorted: exact logins first, then wildcards).
- Run `./devel/regen_bot_lists.py` - it propagates the array to every copy:
  - `util_sql/only_bots.sql` (`like any(array[...])`, used to list bots alone).
  - `util_sql/exclude_bots_table_insert.sql` (fills the `gha_bot_logins` table used by `util_sql/exclude_bots_table.sql` / `util_sql/only_bots_table.sql`; it is run daily by the shared affiliations job `import_affs_shared.sh` from `cncf/devstats-docker-images`).
  - `structure.sql` (`COPY public.gha_bot_logins` block).
  - literal copies in `util_sql/*.sql` (`actors.sql`, `top_actors.sql`, `top_unknown_committers_without_email.sql`, `top_unknown_contributors_without_email.sql`, `bus_and_elaphan_factors.sql`, `istio_developers_report*.sql`, `world_contribut*.sql`, `modify_data_9.sql`) - every `array[...]` containing `'googlebot'`.
  - literal copies in `../devstats-reports/sql/*.sql` (when that repo is checked out next to this one).
  - the Rust compat test fixtures in `../devstatscode/rust/compat/fixtures/` (verbatim copies of `exclude_bots.sql`, `exclude_bots_table_insert.sql`, `actors.sql`).
- Rebuild the docker images (`cncf/devstats-docker-images`: `./images/build_images.sh`, both the golang and the `RUST=1` variants) - the images embed `util_sql/`. Existing metrics are not recomputed, the new list applies to the next calculation.
- Other places (not regenerated by the script):
  - `cncf/devstats-example`: `util_sql/exclude_bots.sql`.
  - `LF-Engineering/dev-analytics-json2hat`: `json2hat.go`: `func updateBots`.
  - `cncf/velocity`: `BigQuery/velocity_*.sql` (especially `BigQuery/velocity_standard_query.sql` and `*condition*.sql` files).

## Auditing the list against live data (how the 2026-09 review was done)

- Dump logins with their event counts from the biggest database (`allprj`), for example: `select coalesce(a.login, e.dup_actor_login), count(*) from gha_events e left join gha_actors a on a.id = e.actor_id group by 1` (also `gha_commits` `dup_author_login`/`dup_committer_login` and `gha_commits_roles` for `Co-authored-by` logins, they go through the same partial).
- Look at the top non-excluded logins matching bot-ish substrings (`bot`, `robot`, `ci`, `automation`, `agent`, `renovate`, `copybara`, `svc`, `team`, `release`, `infra`, `service`, `[bot]`, ` ` (space)) and check every candidate wildcard against the whole login list: a pattern is only acceptable when the humans it catches are negligible (a few events), because `not like all` has no exception list.
- Verified safe wildcards: `%-bot`, `%bot-%`, `%-robot`, `%[%bot]%`, `%ci%bot`, `%cla%bot%`, `%autobot`, `%buildbot%`, `%renovate%`, `%copybara%`, `%automat%`, `%agent`, `%-ci`, `%-gerrit`, `%-infra`, `%-jenkins`, `%-release`, `%-service%`, `%-team%`, `%-testing`, `% bot`, `% ci`, `% team`, `github %`, `github-action%`, `actions%`, `svc%`, `k8s-%`, `jenkins-%`, `travis%bot`, `prom%bot`, `dependabot%`, `codecov%`, `coderabbit%`, `copilot%`, `claassistant%`, `imgbot%`, `mergify%`, `snyk%`, `qodo-%`, `strimzi%`, `cncf-bot%`.
- Verified UNSAFE (real humans with many events): `%bot` (sabbot, jessebot, austbot, ...), `%robot` (rustyrobot, bigangryrobot), `%-bot%` (bottini, bottorff), `%jenkins%`, `%travis%`, `%sonar%`, `%snyk%`, `%stale%`, `%-ai`, `ai-%`, `%-sa`, `%-cd`, `%-machine`, `%-github`, `github-%`, `gh-%`, `%-app`, `%prow%`, `%dco%`, `%lint%`, `%llm%`, `%droid%`, `%kiro%`, `%cline%`, `%bito%`, `%devin%`, `%claude%` (reinhrst is named Claude), `%codex%` (CodexRaunak), `%gemini%`, `dosu%` (dosullivan), `zephyr%` (Zephyrcf), `% %` (git author names used as logins).
- AI coding agents seen so far: `Copilot`, `copilot-pull-request-reviewer[bot]`, `copilot-swe-agent`, `coderabbitai`/`coderabbitai[bot]`, `gemini-code-assist`, `claude`/`claude[bot]`, `codex`/`chatgpt-codex-connector[bot]`, `cursor[bot]`/`cursoragent`, `dosu`/`dosubot[bot]`, `cubic-dev-ai`, `sourcery-ai`, `greptileai`/`greptile-apps[bot]`, `qodo-*`, `codiumai-*`, `devin-ai-integration[bot]`, `augmentcode[bot]`, `openhands-agent`, `kaipilotbot`, `ericwittbot`; most of them are covered by `%[%bot]%`, `copilot%`, `coderabbit%`, `%agent`, `qodo-%` and the explicit logins.
